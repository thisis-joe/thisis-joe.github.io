- defaultdickt(자료형) : 키없이 빈 딕셔너리 생성
- Counter() : 딕셔너리 반환
	- 리스트/문자열 등 반복가능한 객체의 요소 개수 셈
``` python
fruits = ['apple', 'banana', 'apple', 'cheese', 'banana', 'banana']
counter = Counter(fruits)
print("Counter 결과:", dict(counter))  
# {'apple': 2, 'banana': 3, 'cheese': 1}
```
- list()
	- 딕셔너리의 키들을 리스트로 반환
```python
d = {
    1: "apple",
    2: "banana",
    3: "cheese",
}

keys = list(d.keys()) #.keys()로 키들의 ㅇㅇ를 반환, list()로 리스트 반환 
# [1, 2, 3]

value_4 = d.get(4)
assert value_4 is None #.get(키) 는 키가 있으면 값 반환, 없으면 None반환

d2 = {
    4: "dragonfruit"
}

merged = { **d, **d2}  # 딕셔너리 합치기
assert merged == {
    1: "apple",
    2: "banana",
    3: "cheese",
    4: "dragonfruit"
}

```
