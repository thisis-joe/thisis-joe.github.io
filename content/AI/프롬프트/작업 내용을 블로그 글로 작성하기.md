작업 이후에는 이렇게 요청하면 딱 좋습니다.

```
이번 작업 내용을 블로그 글로 정리해줘.

조건:
- 독자가 초급 개발자라고 가정해줘.
- “무엇을 만들었는지”보다 “왜 그런 구조가 필요했는지”를 중심으로 설명해줘.
- 문제 상황 → 잘못된/단순한 접근의 한계 → 최종 설계 원리 → 구현 결과 → 검증 결과 순서로 써줘.
- 너무 길지 않게, 핵심 원리가 이해되도록 써줘.
- 코드 설명은 최소화하고, 데이터 흐름과 판단 기준을 쉽게 풀어줘.
- 문체는 기술 블로그처럼 담백하게 써줘.
```
