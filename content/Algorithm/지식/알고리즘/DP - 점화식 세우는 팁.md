> [!summary]  
> DP는 **작은 문제의 답으로 큰 문제의 답을 만드는 문제**에서 사용한다.  
> 점화식은 보통 “마지막 선택” 또는 “현재 상태”를 기준으로 세운다.
> 
> ```text
> 1. dp[i]가 무엇을 의미하는지 정한다
> 2. 마지막 선택을 기준으로 경우를 나눈다
> 3. 각 경우가 이전 dp 몇 번째에서 오는지 본다
> 4. 경우들을 더하거나 최댓값/최솟값으로 합친다
> 5. 초기값을 직접 세팅한다
> ```
> 
> |문제 표현|DP 의심|
> |---|---|
> |경우의 수|더하기 점화식|
> |최댓값 / 최솟값|Math.max / Math.min|
> |연속된 선택 제한|상태를 나눠야 함|
> |이전 결과를 반복 사용|DP 가능성 높음|
> |모든 경우를 보면 너무 많음|DP 또는 백트래킹 고려|

## 1. 점화식 세우기 핵심

> [!tip]  
> 점화식은 앞에서부터 생각하기보다 **마지막에 무엇을 선택했는지**로 생각하면 쉽다.
> 
> 예를 들어 길이 `n`을 만드는 문제라면:
> 
> ```text
> 마지막에 1칸짜리를 붙였다 -> dp[n - 1]에서 온다
> 마지막에 2칸짜리를 붙였다 -> dp[n - 2]에서 온다
> 마지막에 3칸짜리를 붙였다 -> dp[n - 3]에서 온다
> ```
> 
> 그래서 이런 식이 자주 나온다.
> 
> ```java
> dp[i] = dp[i - 1] + dp[i - 2];
> dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3];
> ```
> 
> 단, “연속 금지”, “이전 색과 달라야 함” 같은 조건이 있으면 `dp[i]` 하나만으로 부족할 수 있다.  
> 이때는 상태를 나눈다.
> 
> ```text
> y[i] = i번째를 노란색으로 끝내는 경우
> b[i] = i번째를 파란색으로 끝내는 경우
> r[i] = i번째를 빨간색으로 끝내는 경우
> ```

## 2. 경우의 수 DP

> [!info]  
> 경우의 수 문제는 보통 마지막 선택을 기준으로 나눈 뒤 더한다.
> 
> 문제: 파랑 1cm, 노랑 1cm, 빨강 2cm 막대로 길이 `n`을 만드는 경우의 수
> 
> ```text
> 마지막이 파랑 1cm -> dp[n - 1]
> 마지막이 노랑 1cm -> dp[n - 1]
> 마지막이 빨강 2cm -> dp[n - 2]
> ```
> 
> 따라서:
> 
> ```java
> dp[i] = dp[i - 1] * 2 + dp[i - 2];
> ```
> 
> 초기값:
> 
> ```java
> dp[0] = 1; // 아무것도 안 붙이는 경우
> dp[1] = 2; // 파, 노
> ```

## 3. 제한 조건이 있는 DP

> [!info]  
> “연속 금지”처럼 이전 선택의 정보가 필요하면 상태를 나눈다.
> 
> 문제: 파랑 1cm, 노랑 1cm, 빨강 2cm로 길이 `n` 만들기.  
> 단, 빨강은 연속으로 사용할 수 없다.
> 
> 상태 정의:
> 
> ```text
> b[n] = 길이 n이 파랑으로 끝나는 경우
> y[n] = 길이 n이 노랑으로 끝나는 경우
> r[n] = 길이 n이 빨강으로 끝나는 경우
> f[n] = 전체 경우의 수
> ```
> 
> 점화식:
> 
> ```text
> b[n] = f[n - 1]
> y[n] = f[n - 1]
> r[n] = b[n - 2] + y[n - 2]
> ```
> 
> 그런데 `b[n - 2] = f[n - 3]`, `y[n - 2] = f[n - 3]` 이므로:
> 
> ```java
> f[n] = b[n] + y[n] + r[n];
> f[n] = 2 * f[n - 1] + 2 * f[n - 3];
> ```
> 
> 핵심은 빨강이 2cm이므로, 마지막에 빨강을 붙이면 `n - 2` 상태를 봐야 한다는 점이다.  
> 그리고 빨강 연속 금지 때문에 `n - 2`가 빨강으로 끝나는 경우는 제외해야 한다.

## 4. 최댓값 / 최솟값 DP

> [!info]  
> 경우의 수는 더하지만, 최댓값/최솟값 문제는 `Math.max`, `Math.min`을 사용한다.
> 
> 예시: 계단 오르기, 경로 최댓값
> 
> ```java
> dp[i] = Math.max(dp[i - 1], dp[i - 2]) + arr[i];
> ```
> 
> 2차원 경로 문제:
> 
> ```java
> dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]) + board[i][j];
> ```
> 
> 의미:
> 
> ```text
> 위에서 오는 경우
> 왼쪽에서 오는 경우
> 둘 중 더 좋은 값을 선택
> 현재 칸 값을 더함
> ```

## 5. 점화식 세울 때 체크리스트

> [!warning]  
> DP에서 자주 틀리는 부분은 점화식보다 `dp 정의`와 `초기값`이다.
> 
> |체크|질문|
> |---|---|
> |dp 정의|`dp[i]`가 정확히 무엇을 의미하는가?|
> |마지막 선택|마지막에 무엇을 붙이거나 선택했는가?|
> |이전 상태|그 선택은 `i-1`, `i-2`, `i-3` 중 어디서 오는가?|
> |상태 분리|이전 색, 이전 선택, 연속 횟수 정보가 필요한가?|
> |초기값|`dp[0]`, `dp[1]`, `dp[2]`를 직접 구했는가?|
> |범위|`i-2`, `i-3` 접근 시 음수 인덱스가 나지 않는가?|
> 
> 점화식이 막히면 이렇게 생각한다.
> 
> ```text
> 마지막 선택을 기준으로 나눈다
> 조건 때문에 이전 선택을 알아야 하면 상태를 쪼갠다
> 경우의 수는 더한다
> 최댓값/최솟값은 max/min 한다
> 초기값은 작은 n을 직접 세어본다
> ```
