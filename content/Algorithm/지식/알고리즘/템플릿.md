## 이분탐색 / 투포인터 / 누적합

> [!summary]  
> 정렬된 배열에서 위치를 찾으면 이분탐색,  
> 양끝에서 좁히면 투포인터,  
> 구간합을 많이 물어보면 누적합이다.
> 
> ```java
> // lowerBound: 처음으로 target 이상인 위치
> int lowerBound(int[] arr, int target) {
>     int l = 0, r = arr.length;
>     while (l < r) {
>         int mid = (l + r) / 2;
>         if (arr[mid] < target) l = mid + 1;
>         else r = mid;
>     }
>     return l;
> }
> 
> // upperBound: 처음으로 target 초과인 위치
> int upperBound(int[] arr, int target) {
>     int l = 0, r = arr.length;
>     while (l < r) {
>         int mid = (l + r) / 2;
>         if (arr[mid] <= target) l = mid + 1;
>         else r = mid;
>     }
>     return l;
> }
> ```
> 
> ```java
> Arrays.sort(arr);
> 
> int left = 0, right = N - 1;
> while (left < right) {
>     int sum = arr[left] + arr[right];
> 
>     if (sum == target) {
>         // 처리
>     }
> 
>     if (sum > target) right--;
>     else left++;
> }
> ```
> 
> ```java
> int[] prefix = new int[N + 1];
> 
> for (int i = 1; i <= N; i++) {
>     prefix[i] = prefix[i - 1] + arr[i];
> }
> 
> int sum = prefix[r] - prefix[l - 1];
> ```

## 그리디

> [!info]  
> 그리디는 “지금 최선의 선택이 전체 최선이 되는가”를 확인해야 한다.  
> 코테에서는 보통 정렬과 함께 나온다.
> 
> 회의실 배정:
> 
> ```java
> Arrays.sort(meetings, (a, b) -> {
>     if (a[1] == b[1]) return Integer.compare(a[0], b[0]);
>     return Integer.compare(a[1], b[1]);
> });
> 
> int end = 0;
> int count = 0;
> 
> for (int[] m : meetings) {
>     if (m[0] >= end) {
>         count++;
>         end = m[1];
>     }
> }
> ```
> 
> 로프:
> 
> ```java
> Arrays.sort(arr);
> 
> int answer = 0;
> for (int i = 0; i < N; i++) {
>     answer = Math.max(answer, arr[i] * (N - i));
> }
> ```

## DP

> [!info]  
> DP는 이전 결과를 저장해서 재사용한다.  
> `dp[i]`의 의미를 먼저 정하고 점화식을 만든다.
> 
> 1차원 DP:
> 
> ```java
> int[] dp = new int[N + 1];
> 
> dp[0] = 0;
> dp[1] = 1;
> 
> for (int i = 2; i <= N; i++) {
>     dp[i] = dp[i - 1] + dp[i - 2];
> }
> ```
> 
> 2차원 경로 DP:
> 
> ```java
> for (int i = 1; i <= N; i++) {
>     for (int j = 1; j <= M; j++) {
>         dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]) + board[i][j];
>     }
> }
> ```
> 
> 0/1 배낭:
> 
> ```java
> for (int i = 1; i <= N; i++) {
>     for (int w = W; w >= weight[i]; w--) {
>         dp[w] = Math.max(dp[w], dp[w - weight[i]] + value[i]);
>     }
> }
> ```

## 위상정렬 / 유니온파인드 / 최단경로

> [!info]  
> 의존 관계는 위상정렬, 집합 연결은 유니온파인드, 가중치 최단거리는 다익스트라를 먼저 떠올린다.
> 
> 위상정렬:
> 
> ```java
> Queue<Integer> q = new ArrayDeque<>();
> 
> for (int i = 1; i <= N; i++) {
>     if (indegree[i] == 0) q.offer(i);
> }
> 
> while (!q.isEmpty()) {
>     int cur = q.poll();
> 
>     for (int next : graph.get(cur)) {
>         if (--indegree[next] == 0) {
>             q.offer(next);
>         }
>     }
> }
> ```
> 
> 유니온파인드:
> 
> ```java
> int[] parent = new int[N + 1];
> 
> for (int i = 1; i <= N; i++) parent[i] = i;
> 
> int find(int x) {
>     if (parent[x] == x) return x;
>     return parent[x] = find(parent[x]);
> }
> 
> void union(int a, int b) {
>     a = find(a);
>     b = find(b);
>     if (a != b) parent[b] = a;
> }
> ```
> 
> 다익스트라:
> 
> ```java
> int[] dist = new int[N + 1];
> Arrays.fill(dist, INF);
> 
> PriorityQueue<int[]> pq = new PriorityQueue<>(
>     (a, b) -> Integer.compare(a[1], b[1])
> );
> 
> dist[start] = 0;
> pq.offer(new int[]{start, 0});
> 
> while (!pq.isEmpty()) {
>     int[] cur = pq.poll();
>     int now = cur[0];
>     int cost = cur[1];
> 
>     if (dist[now] < cost) continue;
> 
>     for (int[] next : graph.get(now)) {
>         int nx = next[0];
>         int nc = next[1];
> 
>         if (dist[nx] > cost + nc) {
>             dist[nx] = cost + nc;
>             pq.offer(new int[]{nx, dist[nx]});
>         }
>     }
> }
> ```
> 
> 플로이드-워셜:
> 
> ```java
> for (int k = 1; k <= N; k++) {
>     for (int i = 1; i <= N; i++) {
>         for (int j = 1; j <= N; j++) {
>             dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
>         }
>     }
> }
> ```
