## 1. 그래프 문제는 먼저 비용 / 가중치 중 무엇이 핵심인지 결정하자.

> [!summary]  
> 그래프 문제는 먼저 **비용/가중치가 핵심인지**를 본다.  
> 비용이 핵심이 아니면 `탐색`, 비용을 최소화해야 하면 `MST` 또는 `최단경로`로 나눈다.
> 
> ```text
> 그래프 문제
> ├─ 탐색 문제
> │  ├─ 연결 확인             : 갈 수 있는가 / 연결되어 있는가           → BFS / DFS
> │  ├─ 연결 요소             : 연결된 그룹이 몇 개인가                  → BFS / DFS
> │  ├─ 전체 경우 탐색        : 모든 경우를 탐색해야 하는가              → DFS / 백트래킹
> │  └─ 무가중치 최단거리     : 몇 칸 만에 도착 / 최소 이동 횟수         → BFS
> │
> └─ 최소비용 문제
>    ├─ 전체 연결 비용
>    │  ├─ 표현               : 모든 도시 연결 / 네트워크 구성 비용 최소 / 간선을 골라 전체 연결 비용 최소 / 모든 정점을 싸게 연결
>    │  └─ 알고리즘           : MST                                      → Kruskal / Prim
>    │
>    └─ 경로 이동 비용
>       ├─ 표현               : A에서 B까지 최소 비용 / 최소 시간으로 도착 / 1번에서 모든 정점까지 최단거리 / 특정 지점까지 싸게 이동
>       └─ 알고리즘           : 최단경로
>          ├─ 가중치 없음     : 모든 간선 비용이 1 / 최소 이동 횟수      → BFS
>          ├─ 가중치 0 또는 1 : 비용이 0인 이동과 1인 이동만 존재        → 0-1 BFS
>          ├─ 양수 가중치     : 도로 비용 / 이동 시간 / 거리가 모두 양수 → Dijkstra
>          ├─ 음수 간선       : 비용이 음수인 간선 존재                  → Bellman-Ford
>          └─ 모든 쌍 거리    : 모든 i에서 j까지 최소 비용               → Floyd-Warshall
>
> [요약]
> - BFS / DFS        : 갈 수 있는지, 몇 개 연결됐는지 탐색
> - MST              : 전체를 싸게 연결
> - 최단경로          : 목적지까지 싸게 이동
> - BFS 최단거리      : 가중치 없는 최소 이동 횟수
> - 0-1 BFS          : 가중치가 0 또는 1인 최단경로
> - Dijkstra         : 음수 없는 가중치 최단경로
> - Bellman-Ford     : 음수 간선이 있는 최단경로
> - Floyd-Warshall   : 모든 정점 쌍 최단경로
> ```

## 2. BFS / DFS 선택 기준

> [!info]  
> 그래프·격자 문제는 보통 BFS/DFS부터 생각한다.
> 
> |상황|추천|
> |---|---|
> |최단 거리 / 최소 이동 횟수|BFS|
> |미로 탐색|BFS|
> |연결 요소 개수|BFS 또는 DFS|
> |Flood Fill|BFS 또는 DFS|
> |백트래킹 / 모든 경우 탐색|DFS|
> |재귀 깊이가 너무 깊음|BFS 또는 반복문 DFS|
> 
> 핵심:
> 
> ```text
> 최단거리 → BFS
> 연결 확인 → BFS / DFS
> 모든 경우 탐색 → DFS
> ```

## 3. BFS 기본형

> [!info]  BFS는 `Queue`또는 `ArrayDeque`를 쓴다.
> 
> ```java
> Queue<int[]> q = new ArrayDeque<>();
> q.offer(new int[]{sx, sy});
> visited[sx][sy] = true;
> 
> while (!q.isEmpty()) {
>     int[] cur = q.poll();
>     int x = cur[0];
>     int y = cur[1];
> 
>     for (int dir = 0; dir < 4; dir++) {
>         int nx = x + dx[dir];
>         int ny = y + dy[dir];
> 
>         if (nx < 0 || ny < 0 || nx >= N || ny >= M) continue;
>         if (visited[nx][ny]) continue;
> 
>         visited[nx][ny] = true;
>         q.offer(new int[]{nx, ny});
>     }
> }
> ```

---

## 4. BFS 거리 계산

> [!info]  최단거리 문제에서는 `visited` 대신 `dist`를 쓰면 편하다.  
> `dist`를 `-1`로 초기화하면 방문 여부와 거리를 동시에 관리할 수 있다.
> 
> ```java
> int[][] dist = new int[N][M];
> for (int[] row : dist) {
>     Arrays.fill(row, -1);
> }
> 
> Queue<int[]> q = new ArrayDeque<>();
> q.offer(new int[]{sx, sy});
> dist[sx][sy] = 0;
> 
> while (!q.isEmpty()) {
>     int[] cur = q.poll();
>     int x = cur[0];
>     int y = cur[1];
> 
>     for (int dir = 0; dir < 4; dir++) {
>         int nx = x + dx[dir];
>         int ny = y + dy[dir];
> 
>         if (nx < 0 || ny < 0 || nx >= N || ny >= M) continue;
>         if (dist[nx][ny] != -1) continue;
> 
>         dist[nx][ny] = dist[x][y] + 1;
>         q.offer(new int[]{nx, ny});
>     }
> }
> ```
> 
> 가중치가 없는 그래프에서 최단거리는 BFS로 푼다.

## 5. DFS 기본형

> [!info]  DFS는 연결 요소 개수, Flood Fill, 백트래킹에서 자주 사용한다.
> 
> ```java
> void dfs(int x, int y) {
>     visited[x][y] = true;
> 
>     for (int dir = 0; dir < 4; dir++) {
>         int nx = x + dx[dir];
>         int ny = y + dy[dir];
> 
>         if (nx < 0 || ny < 0 || nx >= N || ny >= M) continue;
>         if (visited[nx][ny]) continue;
> 
>         dfs(nx, ny);
>     }
> }
> ```
> 
> 연결 요소 개수:
> 
> ```java
> int count = 0;
> 
> for (int i = 1; i <= N; i++) {
>     if (!visited[i]) {
>         dfs(i);
>         count++;
>     }
> }
> ```

## 6. MST

> [!summary]  MST는 최소 신장 트리를 의미하며,  모든 정점을 연결하는 비용의 합을 최소로 한다. 
> 신장트리는 `V`개의 정점과 `V - 1`개의 간선으로 이루어지며, 사이클이 없어야 한다.
> 
> ```text
> 정점 V개
> 간선 V - 1개
> 사이클 없음
> 모든 정점 연결
> 가중치 합 최소
> ```
> 
> 문제 표현:
> 
> ```text
> 모든 도시를 최소 비용으로 연결
> 모든 섬을 다리로 연결하는 최소 비용
> 네트워크를 최소 비용으로 구성
> ```
> 
> 이런 표현이면 `Kruskal` 또는 `Prim`을 생각한다.

## 6-1. Kruskal

> [!info]  Kruskal은 간선을 가중치 오름차순으로 정렬한 뒤, 사이클이 생기지 않는 간선만 선택한다.  
> 사이클 판별은 `Union-Find`로 한다.
> 
> ```text
> 간선 정렬
> → 가장 싼 간선부터 확인
> → 사이클 없으면 선택
> → V - 1개 선택하면 종료
> ```
> 
> ```java
> static class Edge {
>     int a, b, cost;
> 
>     Edge(int a, int b, int cost) {
>         this.a = a;
>         this.b = b;
>         this.cost = cost;
>     }
> }
> 
> Arrays.sort(edges, (e1, e2) -> Integer.compare(e1.cost, e2.cost));
> 
> int answer = 0;
> int count = 0;
> 
> for (Edge e : edges) {
>     if (find(e.a) != find(e.b)) {
>         union(e.a, e.b);
>         answer += e.cost;
>         count++;
> 
>         if (count == V - 1) break;
>     }
> }
> ```
> 
> Union-Find:
> 
> ```java
> int[] parent = new int[V + 1];
> 
> for (int i = 1; i <= V; i++) {
>     parent[i] = i;
> }
> 
> int find(int x) {
>     if (parent[x] == x) return x;
>     return parent[x] = find(parent[x]);
> }
> 
> void union(int a, int b) {
>     a = find(a);
>     b = find(b);
> 
>     if (a != b) parent[b] = a;
> }
> ```
> 
> 시간복잡도:
> 
> ```text
> O(E log E)
> ```
> 
> MST 문제에서 구현이 쉬워서 보통 Kruskal을 먼저 떠올린다.

## 6-2. Prim

> [!info]  Prim은 정점 하나에서 시작해서, 현재 연결된 정점 집합에서 갈 수 있는 가장 싼 간선을 계속 선택한다.
> 
> ```text
> 시작 정점 선택
> → 갈 수 있는 간선을 PQ에 넣음
> → 가장 싼 간선 선택
> → 이미 방문한 정점이면 스킵
> → 모든 정점 방문까지 반복
> ```
> 
> ```java
> static class Edge {
>     int to, cost;
> 
>     Edge(int to, int cost) {
>         this.to = to;
>         this.cost = cost;
>     }
> }
> 
> boolean[] visited = new boolean[V + 1];
> PriorityQueue<Edge> pq = new PriorityQueue<>(
>     (a, b) -> Integer.compare(a.cost, b.cost)
> );
> 
> pq.offer(new Edge(1, 0));
> 
> int answer = 0;
> int count = 0;
> 
> while (!pq.isEmpty()) {
>     Edge cur = pq.poll();
> 
>     if (visited[cur.to]) continue;
> 
>     visited[cur.to] = true;
>     answer += cur.cost;
>     count++;
> 
>     if (count == V) break;
> 
>     for (Edge next : graph.get(cur.to)) {
>         if (!visited[next.to]) {
>             pq.offer(next);
>         }
>     }
> }
> ```
> 
> 시간복잡도:
> 
> ```text
> O(E log V)
> ```

## 7. 최단경로

> [!summary]  출발점에서 도착점까지 이동 비용을 최소화하는 문제다.
> 
> |상황|추천|
> |---|---|
> |가중치 없음|BFS|
> |가중치 있음, 음수 없음|Dijkstra|
> |음수 간선 있음|Bellman-Ford|
> |모든 정점 쌍 최단거리|Floyd-Warshall|
> |가중치가 0 또는 1|0-1 BFS|
> 
> 문제 표현:
> 
> ```text
> A에서 B까지 최소 비용
> 1번에서 모든 정점까지 최단거리
> 최소 시간으로 도착
> 모든 도시 쌍의 최단거리
> ```

## 8. Dijkstra

> [!info]  Dijkstra는 시작 정점에서 다른 정점까지의 최단거리를 구한다.  
> 간선 가중치가 음수이면 사용할 수 없다.
> 
> ```text
> 시작점 dist = 0
> → 현재 가장 가까운 정점 선택
> → 인접 정점 거리 갱신
> → PQ로 최소 거리 후보 관리
> ```
> 
> ```java
> static class Node {
>     int to, cost;
> 
>     Node(int to, int cost) {
>         this.to = to;
>         this.cost = cost;
>     }
> }
> 
> int[] dist = new int[V + 1];
> Arrays.fill(dist, INF);
> 
> PriorityQueue<Node> pq = new PriorityQueue<>(
>     (a, b) -> Integer.compare(a.cost, b.cost)
> );
> 
> dist[start] = 0;
> pq.offer(new Node(start, 0));
> 
> while (!pq.isEmpty()) {
>     Node cur = pq.poll();
> 
>     if (dist[cur.to] < cur.cost) continue;
> 
>     for (Node next : graph.get(cur.to)) {
>         int newCost = dist[cur.to] + next.cost;
> 
>         if (newCost < dist[next.to]) {
>             dist[next.to] = newCost;
>             pq.offer(new Node(next.to, newCost));
>         }
>     }
> }
> ```
> 
> 시간복잡도:
> 
> ```text
> O(E log V)
> ```
