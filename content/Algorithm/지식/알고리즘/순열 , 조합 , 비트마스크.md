## 순열 / 조합

> [!summary]  
> 순서가 중요하면 순열, 순서가 중요하지 않으면 조합이다.
> 
> |유형|의미|
> |---|---|
> |순열|뽑는 순서가 다르면 다른 경우|
> |조합|뽑는 순서가 달라도 같은 경우|
> 
> 조합:
> 
> ```java
> List<Integer> path = new ArrayList<>();
> 
> void comb(int start, int depth) {
>     if (depth == R) {
>         // path 처리
>         return;
>     }
> 
>     for (int i = start; i < N; i++) {
>         path.add(arr[i]);
>         comb(i + 1, depth + 1);
>         path.remove(path.size() - 1);
>     }
> }
> ```
> 
> 순열:
> 
> ```java
> boolean[] used = new boolean[N];
> List<Integer> path = new ArrayList<>();
> 
> void perm(int depth) {
>     if (depth == R) {
>         // path 처리
>         return;
>     }
> 
>     for (int i = 0; i < N; i++) {
>         if (used[i]) continue;
> 
>         used[i] = true;
>         path.add(arr[i]);
> 
>         perm(depth + 1);
> 
>         path.remove(path.size() - 1);
>         used[i] = false;
>     }
> }
> ```

## 조합 수 계산

> [!info]  
> 조합 값을 직접 계산해야 하면 범위를 먼저 본다.  
> 값이 커질 수 있으면 `long`도 쉽게 넘는다.  30 C 15 = 1억5천만
> 
> ```java
> long[][] dp = new long[N + 1][N + 1];
> 
> for (int n = 0; n <= N; n++) {
>     dp[n][0] = dp[n][n] = 1;
> 
>     for (int r = 1; r < n; r++) {
>         dp[n][r] = dp[n - 1][r - 1] + dp[n - 1][r];
>     }
> }
> ```
> 
> 매우 큰 조합 값이 필요하면 `BigInteger`를 사용한다.

## 비트마스크

> [!info]  
> 비트마스크는 작은 집합의 선택 여부를 정수 하나로 표현할 때 사용한다.  
> 보통 `N <= 20` 정도의 부분집합 탐색에서 자주 나온다.
> 
> ```java
> for (int mask = 0; mask < (1 << N); mask++) {
>     for (int i = 0; i < N; i++) {
>         if ((mask & (1 << i)) != 0) {
>             // i번째 원소 선택됨
>         }
>     }
> }
> ```
> 
> 기본 연산:
> 
> ```java
> mask |= (1 << i);              // i번째 원소 추가
> mask &= ~(1 << i);             // i번째 원소 제거
> boolean has = (mask & (1 << i)) != 0; // i번째 원소 포함 여부
> ```
> 
> 2의 거듭제곱 판별:
> 
> ```java
> boolean ok = n > 0 && (n & (n - 1)) == 0;
> ```
