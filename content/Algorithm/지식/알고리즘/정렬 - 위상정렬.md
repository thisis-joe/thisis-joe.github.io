> [!info]  위상정렬은 `작업 순서`, `선수 과목`, `프로젝트 의존성`처럼 선후관계가 있는 문제에서 사용한다.
> 
> ```java
> Queue<Integer> q = new ArrayDeque<>();
> 
> for (int i = 1; i <= N; i++) {
>     if (indegree[i] == 0) {
>         q.offer(i);
>     }
> }
> 
> while (!q.isEmpty()) {
>     int cur = q.poll();
> 
>     for (int next : graph.get(cur)) {
>         indegree[next]--;
> 
>         if (indegree[next] == 0) {
>             q.offer(next);
>         }
>     }
> }
> ```
> 
> 핵심:
> 
> ```text
> 진입차수 0인 노드부터 큐에 넣는다
> 꺼낸 노드와 연결된 다음 노드의 진입차수를 1 줄인다
> 진입차수가 0이 되면 큐에 넣는다
> ```
