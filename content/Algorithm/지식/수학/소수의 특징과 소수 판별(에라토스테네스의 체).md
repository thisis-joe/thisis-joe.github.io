**소수의 특징**
- 100이하 소수의 개수 :  25개
- 소수는 n > 3일 때, 6k ± 1 형태만 가능하다.
```clojure
    5  = 6 * 1 - 1
    7  = 6 * 1 + 1
    11 = 6 * 2 - 1
    13 = 6 * 2 + 1
    17 = 6 * 3 - 1
    19 = 6 * 3 + 1
    ...
```

**소수판별(에라토스테네스의 체)**
1. 선언
	- boolean[] isPrime = boolean[n+1]      // 1-index
2. 초기화
	- 해당 범위 모두 소수로 가정. Arrays.fill(isPrime,true) 
	- 0과 1은 소수가 아님. false.
3. 판별 로직
	- 최소 소수(2)시작, √n까지 순회
		- 범위 내에서 해당 소수의 배수들을 false 처리.
		- 해당 소수는 제외 
4. 출력
	- true인 isPrime[i]

```java
public int solution(int n) {
        
  boolean[] isPrime = new boolean[n+1];
  Arrays.fill(isPrime,true);
  
  isPrime[0] = false; isPrime[1] = false;
  
  for(int p = 2 ; p * p <= n ; i++){ // √n까지 순회
      if(isPrime[p]){ //소수일때
          for(int q = p * p; q <= n ; q += i){ // 해당 소수는 제외
              isPrime[q] = false;    
          }
      }
  }
  
  int cnt = 0;
  for (int i = 2; i <= n; i++) {
      if (isPrime[i]) cnt++;
  }
  
  return cnt;
}
```
