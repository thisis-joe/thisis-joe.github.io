## ArrayDeque 정책 반영

|항목|처리|
|---|---|
|`Stack` 클래스 지양|`Deque<T> st = new ArrayDeque<>();` + `push/pop/peek`로 통일|
|`LinkedList` 큐 지양|`Queue<T> q = new ArrayDeque<>();` + `offer/poll/peek`로 통일|
|큐/스택/덱 메서드 분리|`ArrayDeque.md`에 표로 정리|
|`push()` 방향|앞에 넣는 동작으로 강조|
|`offer()`/`offerLast()` 방향|뒤에 넣는 동작으로 강조|
|`poll()`/`pollFirst()` 방향|앞에서 꺼내는 동작으로 강조|
|배열 변환 순서|`stream().mapToInt(i -> i).toArray()`는 현재 앞 → 뒤 순서임을 명시|
|실수 사례|`push()`로 큐를 구현해 결과가 역순이 되는 예시와 수정 코드 추가|
|빈 덱 처리|`poll/peek`은 null, `remove/get`은 예외로 비교|
|`null` 삽입|`ArrayDeque`는 `null` 불가 명시|
