### Character
```java
Character.isUpperCase(문자)
Character.toUpperCase(문자)
Character.isLowerCase(문자)
Character.toLowerCase(문자)

Character.isDigit(문자)       // 숫자면 true
Character.isAlphabetic(문자)  // 알파벳이면 true
```

### Characters
```java
Characters.isDigit(문자)      // 숫자면 true
Characters.isLetter(문자)     // 알파벳이면 true
Characters.isWhitespace(문자) // 공백이면 true
```
