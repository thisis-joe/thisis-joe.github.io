## 문제 풀이 루틴

```text
1. 제약조건을 보고 가능한 시간복잡도를 먼저 정한다.
2. 문제 표현을 00_메타/01 매핑표에 대입한다.
3. 후보 알고리즘 문서의 “문제 신호”와 “자주 하는 실수”를 본다.
4. 코드를 보기 전에 “백지 복원 질문”에 답한다.
5. 템플릿을 손으로 복원하고, 입력/출력/자료형을 문제에 맞게 바꾼다.
6. 제출 직전 00_메타/03 엣지케이스를 체크한다.
7. 틀리면 00_메타/02 오답-약점 로그에 원인을 한 줄로 남긴다.
```

## 이 문서 집합의 Java 기준

```text
- Java 17 기준
- 기본 입력: BufferedReader + StringTokenizer
- 대량 출력: StringBuilder
- 큐: Queue<T> q = new ArrayDeque<>() + offer/poll/peek
- 스택: Deque<T> st = new ArrayDeque<>() + push/pop/peek
- 덱 직접 조작: Deque<T> dq = new ArrayDeque<>() + offerFirst/offerLast/pollFirst/pollLast
- Stack 클래스와 LinkedList 큐는 특별한 이유가 없으면 쓰지 않는다.
```
