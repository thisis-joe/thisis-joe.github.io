## Stack / Queue / Deque

```text
큐처럼 쓰는데 push()를 쓰지 않았는가?
push()는 앞에 넣는 동작임을 확인했는가?
offer()/offerLast()는 뒤에 넣는 동작임을 확인했는가?
poll()/pollFirst()는 앞에서 꺼내는 동작임을 확인했는가?
stream().mapToInt(i -> i).toArray() 결과는 현재 앞 → 뒤 순서인가?
스택처럼 push()로 넣었다면 배열 변환 시 삽입 역순이 되는가?
ArrayDeque에 null을 넣지 않는가?
poll/peek 결과 null을 int로 바로 언박싱하지 않는가?
remove/get 계열은 빈 덱에서 예외가 난다는 점을 확인했는가?
방향이 필요한 문제에서 offerFirst/offerLast/pollFirst/pollLast를 명시했는가?
```
