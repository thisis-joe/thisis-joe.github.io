# 문제 신호 → 알고리즘 매핑

> [!summary]
> 문제를 읽고 “어떤 템플릿을 꺼낼지” 결정하는 표다.  
> 한 문제에 신호가 여러 개 보이면 `제약조건 → 그래프/배열/문자열 형태 → 최적화 여부` 순서로 좁힌다.

---

## 제약조건 신호

|문제 신호|먼저 의심|대표 복잡도|
|---|---|---|
|`N <= 10`, 모든 순서|순열, 백트래킹|`O(N!)`|
|`N <= 20`, 선택/미선택|부분집합, 비트마스크|`O(2^N)`|
|`N <= 30`, 경우의 수가 큼|Meet-in-the-middle, 조합 DP|`O(2^(N/2))` 후보|
|`N <= 500`, 모든 쌍|Floyd, 3중 for DP|`O(N^3)`|
|`N <= 2,000`|2중 for, LIS O(N²), DP|`O(N^2)`|
|`N <= 100,000`|정렬, 이분탐색, 해시, PQ|`O(N log N)` 이하|
|`N <= 1,000,000`|누적합, BFS/DFS, 투포인터|`O(N)` 중심|
|격자 `N*M <= 1,000,000`|BFS/DFS/시뮬레이션|`O(NM)`|
|정점 `V`, 간선 `E`|그래프 탐색/최단경로|`O(V+E)` 또는 `O(E log V)`|

## Java 자료구조 신호

|상황|선택|금지/주의|
|---|---|---|
|BFS 일반 큐|`Queue<T> q = new ArrayDeque<>();`|큐처럼 쓰면서 `push()` 금지|
|스택 문제|`Deque<T> st = new ArrayDeque<>();` + `push/pop/peek`|`Stack` 클래스 지양|
|양쪽 조작|`Deque<T> dq = new ArrayDeque<>();` + `offerFirst/offerLast`|방향 없는 `push/offer` 혼용 금지|
|중복 제거 + 순서 유지|`LinkedHashSet` 또는 `Deque` + 마지막 값 변수|`HashSet` 순서 보장 X|
|정렬 기준 있는 힙|`PriorityQueue<>(Comparator)`|`a - b` Comparator 금지|
|큰 수 산술|`BigInteger`|`+`, `*` 연산자 사용 불가|

## 위험 신호

|신호|확인|
|---|---|
|비용 합, 거리 합|`int` 대신 `long` 필요 여부|
|경우의 수|mod 연산 여부, `long` 초과 여부|
|재귀 깊이 `100,000`|StackOverflow 위험. 반복 DFS/BFS 고려|
|중복 간선|최소 비용만 유지할지 확인|
|시작 == 도착|초기값으로 답이 바로 나오는지 확인|
|도달 불가능|`INF` 출력 규칙 확인|
|정렬 Comparator|`a - b` 금지, `Integer.compare()` 사용|
|Deque를 배열로 변환|현재 앞 → 뒤 순서. `push()`로 넣은 스택은 삽입 역순|
|`ArrayDeque`에 `null` 삽입|불가능. `poll()` 결과 null 언박싱 NPE 주의|
