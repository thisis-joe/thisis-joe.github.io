# 스택 - 괄호 / 단조 스택

> [!summary]
> “직전 것과 비교해 짝을 맞추거나 지운다”, “여는/닫는 구조”가 나오면 스택이다.  
> Java에서는 `Stack` 클래스가 아니라 `Deque<T> st = new ArrayDeque<>();`를 쓴다.

---

## 언제 쓰는가

|문제 신호|처리|
|---|---|
|괄호 짝 맞추기|여는 건 `push`, 닫는 건 `peek/pop`|
|인접한 짝 제거|top과 같으면 pop, 아니면 push|
|문자 폭발|스택 또는 StringBuilder를 스택처럼 사용|
|수식 / 후위 표기|연산자 우선순위 스택|
|직전보다 큰/작은 값 추적|단조 스택, 인덱스 저장|

> [!important]
> Queue/Stack/Deque 메서드 방향표는 `문법/A_필수/ArrayDeque.md`를 대표로 본다.

---

## 복잡도

|작업|복잡도|
|---|---|
|괄호 검증|`O(N)`|
|인접 제거|`O(N)`|
|단조 스택|`O(N)`|
|공간|`O(N)`|

## 올바른 괄호 검증 템플릿

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine().trim());

        StringBuilder sb = new StringBuilder();
        for (int t = 0; t < n; t++) {
            String s = br.readLine();
            sb.append(isValid(s) ? "YES" : "NO").append('\n');
        }
        System.out.print(sb);
    }

    static boolean isValid(String s) {
        Deque<Character> st = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                st.push(c);
                continue;
            }

            if (st.isEmpty()) return false;
            char open = st.pop();

            if (c == ')' && open != '(') return false;
            if (c == ']' && open != '[') return false;
            if (c == '}' && open != '{') return false;
        }

        return st.isEmpty();
    }
}
```

## 인접 짝 제거

```java
static String removeAdjacent(String s) {
    Deque<Character> st = new ArrayDeque<>();

    for (char c : s.toCharArray()) {
        if (!st.isEmpty() && st.peek() == c) {
            st.pop();
        } else {
            st.push(c);
        }
    }

    StringBuilder sb = new StringBuilder();
    while (!st.isEmpty()) sb.append(st.pop());
    return sb.reverse().toString();
}
```

`push()`로 앞에 넣었기 때문에 마지막에 `reverse()`가 필요하다.

## 단조 스택 - 오큰수 핵심

```java
int[] ans = new int[n];
Arrays.fill(ans, -1);
Deque<Integer> st = new ArrayDeque<>(); // 인덱스 저장

for (int i = 0; i < n; i++) {
    while (!st.isEmpty() && arr[st.peek()] < arr[i]) {
        ans[st.pop()] = arr[i];
    }
    st.push(i);
}
```

---

## 자주 하는 실수

|실수|주의|
|---|---|
|닫는 괄호에서 빈 스택 확인 누락|`st.isEmpty()` 먼저|
|마지막에 스택이 비었는지 확인 누락|열린 괄호가 남으면 실패|
|인접 제거 결과를 뒤집지 않음|`push()`는 앞에 넣으므로 reverse 필요|
|단조 스택에 값 저장|정답 위치가 필요하면 인덱스 저장|
|`Stack` 클래스 사용|`Deque<T> st = new ArrayDeque<>();` 권장|
