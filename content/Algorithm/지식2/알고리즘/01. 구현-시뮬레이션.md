# 구현 / 시뮬레이션

> [!summary]
> 삼성/SWEA/카카오 초중반 문제는 알고리즘보다 구현 실수가 더 자주 터진다.  
> 격자 이동, 배열 복사, 회전, 동시 처리, 단계 진행을 먼저 고정한다.

---

## 자주 나오는 신호

|문제 신호|처리|
|---|---|
|격자에서 객체가 움직임|방향 배열 + 범위 체크|
|매 초/매 턴 상태 변화|새 배열에 다음 상태 기록|
|동시에 이동|결과 배열 또는 충돌 카운트 배열 사용|
|배열 회전|새 배열에 좌표 변환|
|원본 보존 필요|2차원 deep copy|
|벽 세우고 탐색|조합 + BFS|

## 90도 회전 + 2차원 deep copy 검증 템플릿

> [!info]
> `copy = board.clone()`은 2차원 배열에서 얕은 복사다.  
> 행마다 `clone()`해야 한다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int n = Integer.parseInt(br.readLine());
        int[][] board = new int[n][n];

        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 0; j < n; j++) {
                board[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int[][] rotated = rotateRight(board);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                sb.append(rotated[i][j]);
                if (j < n - 1) sb.append(' ');
            }
            sb.append('\n');
        }
        System.out.print(sb);
    }

    static int[][] rotateRight(int[][] board) {
        int n = board.length;
        int[][] result = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                result[j][n - 1 - i] = board[i][j];
            }
        }

        return result;
    }

    static int[][] copyBoard(int[][] board) {
        int n = board.length;
        int[][] copy = new int[n][];
        for (int i = 0; i < n; i++) {
            copy[i] = board[i].clone();
        }
        return copy;
    }
}
```

## 동시 처리 원칙

> [!warning]
> 한 객체를 움직이자마자 원본 배열을 바꾸면 뒤 객체 판단이 꼬일 수 있다.

```text
1. 현재 board를 기준으로 모든 객체의 이동 후보를 계산한다.
2. nextBoard 또는 countBoard에 결과를 기록한다.
3. 충돌/삭제/합체를 처리한다.
4. board = nextBoard로 교체한다.
```

```text

```
